# covid-life-expectancy-analysis

## Project Overview
This project analyzes changes in male and female life expectancy in Canada from 2019 to 2024 using data from the World Bank. The analysis explores trends before, during, and after the COVID-19 pandemic and compares life expectancy between males and females.

## Objectives
- Visualize changes in male and female life expectancy over time.
- Compare life expectancy during the COVID-19 period (2020–2022).
- Test for differences between males and females using a Welch two-sample t-test.

## Data Source
World Bank Open Data (WDI package in R)

## Repository Contents
- `code/` – Contains the R script used for data analysis and visualization.
- `results/` – Contains figures and statistical results generated from the analysis.
- `README.md` – Project overview and documentation.

## Statistical Methods
- Descriptive statistics
- Line graph
- Welch two-sample t-test
